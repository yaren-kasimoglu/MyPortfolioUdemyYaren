# 🚀 ASP.NET Core Portfolio Application

ASP.NET Core MVC kullanılarak geliştirilmiş dinamik bir kişisel portfolio uygulamasıdır.

Bu proje, Murat Yücedağ'ın Udemy üzerindeki **ASP.NET Core ile Portfolio Uygulamanızı Geliştirin** eğitimi kapsamında geliştirilmiş ve kendi bilgilerim ile içeriklerime göre özelleştirilmiştir.

## 📌 Proje Hakkında

Uygulama, kişisel bilgilerin, yeteneklerin, iş deneyimlerinin ve projelerin dinamik olarak yönetilebildiği bir portfolio sitesi ve admin panelinden oluşmaktadır.

Admin paneli üzerinden portfolio içerisindeki içerikler veritabanı üzerinden yönetilebilmektedir.

## 🛠️ Kullanılan Teknolojiler

- ASP.NET Core MVC
- C#
- Entity Framework Core
- Microsoft SQL Server
- LINQ
- Razor View
- View Components
- HTML / CSS

## ✨ Özellikler

- Dinamik hakkımda alanı
- Yetenek yönetimi
- İş deneyimi yönetimi
- Portfolio / proje yönetimi
- İletişim mesajları
- Sosyal medya bilgilerinin yönetimi
- To-Do List sistemi
- Okundu / okunmadı mesaj yönetimi
- Admin paneli
- SQL Server veritabanı entegrasyonu

## 🗄️ Veritabanı

Projede Entity Framework Core kullanılarak SQL Server ile bağlantı kurulmuştur.

Başlıca tablolar:

- Abouts
- Experiences
- Skills
- Portfolios
- Messages
- Contacts
- SocialMedias
- Testimonials
- ToDoLists

## 🎯 Amaç

Bu projeyi geliştirirken ASP.NET Core MVC mimarisini uygulamalı olarak öğrenmek; Entity Framework Core, SQL Server, Razor View ve View Component yapılarını kullanarak dinamik bir web uygulaması geliştirme konusunda deneyim kazanmak amaçlanmıştır.
